# DPDP Readiness Baseline

For India DPDP Act 2023 / DPDP Rules 2025 readiness: purpose limitation, data minimisation, clear notice/consent where applicable, rights workflows, access controls, encryption, retention/deletion, processor governance, incident response, child-data safeguards where applicable, and privacy-by-design.

Maintain a data inventory, purpose register, data-flow map, retention schedule, processor register and access matrix. Never put identifiable personal data in Git or CI logs.

Legal note: technical readiness checklist only; not legal advice or a compliance certification.
